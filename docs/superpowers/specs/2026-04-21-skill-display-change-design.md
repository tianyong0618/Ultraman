# 技能展示调整设计

## 变更概述

**变更编号**: CP-007
**变更日期**: 2026-04-21
**变更类型**: 需求变更
**状态**: 设计完成，待用户审批

## 问题描述

当前系统中存在以下问题：
1. **功能重复**："技能"标签页与"技能展示"区域功能重复
2. **展示不完整**："技能展示"区域只显示第1个技能按钮，而非全部技能
3. **音频不独立**：技能音频为整合文件，需每个技能独立音频

## 设计方案

### 方案A（推荐）：移除技能标签页 + 完整技能展示

#### UI变更

1. **标签页调整**：
   - 当前：5个标签 [简介, 形态, 技能, 人间体, 台词]
   - 调整后：4个标签 [简介, 人间体, 台词, 形态]
   - 移除了"技能"标签页，将"形态"移到最后

2. **技能展示区域**：
   - 显示该奥特曼的**全部技能**
   - 每个技能一个独立按钮
   - 点击技能按钮 → 播放该技能对应的独立音频

#### 技术变更

1. **数据层** (`src/data/ultraman.js`):
   - `infoLabels` 改为 `['简介', '人间体', '台词', '形态']`

2. **UI层** (`src/components/UltramanInfo.jsx`):
   - 修改TabContent，移除技能标签页内容（index=2）
   - 修改技能展示区，遍历 `current.skills` 渲染所有技能按钮
   - 点击技能按钮时调用 `onPlaySkill(index)` 传入技能索引

3. **音效层** (`src/hooks/useMagicBook.js`):
   - 修改 `playSkill(skillIndex)` 使用新命名规则：
     - 文件路径：`/audio/skills/奥特曼名称_技能名称.mp3`
     - 例如：`/audio/skills/初代奥特曼_斯派修姆光线.mp3`

4. **音频生成**:
   - 使用 edge_tts 为每个技能的每个技能生成独立音频
   - 命名规则：`{奥特曼名称}_{技能名称}.mp3`
   - 保存路径：`/public/audio/skills/`
