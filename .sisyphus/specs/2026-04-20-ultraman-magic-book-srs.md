## 1. 项目概述

### 1.1 项目背景

Ultraman Magic Book（奥特曼魔法书）是一个面向儿童的互动百科全书Web应用，以古典魔法书的形式呈现1966年至2024年间29个正统奥特曼系列作品。用户可以浏览翻阅魔法书，查看每位奥特曼的详细信息，切换形态，触发技能音效，并聆听语音朗读。

### 1.2 核心用户

| 角色 | 描述 | 优先级 |
|------|------|--------|
| 主要用户 | 4-10岁儿童 | P0 |
| 次要用户 | 家长/成人 | P1 |

### 1.3 产品目标

1. 以视觉吸引力引导儿童了解奥特曼历史
2. 培养阅读兴趣和探索精神
3. 提供沉浸式交互体验
4. 传承奥特曼系列文化

### 1.4 关键约束

- 无需用户登录/注册
- 支持离线缓存阅读
- 响应式布局适配多终端

### 1.5 开发约束（强制）

| 约束 | 描述 |
|------|------|
| 约束1 | 开发过程中必须逐个更新 REQ 状态，禁止批量更新 |
| 约束2 | 归档时必须交叉检查所有待实施提案，确保文档状态与实际代码状态一致 |
| 约束3 | 禁止跳过提案确认步骤直接修改代码 |
| 约束4 | 所有变更必须生成可追溯的文档 |
| 约束5 | 主规范文档必须与代码实现保持一致 |

## 2. 功能规范

### 2.1 功能模块

#### 2.1.1 魔法书封面 (BookCover)

**功能描述**: 应用启动时的初始界面，引导用户进入

**界面元素**:
- 魔法书封面图案（皮革纹理+金色边框）
- 标题"奥特曼魔法书"
- 副标题"ULTRAMAN MAGIC BOOK"
- "✦ 开启旅程 ✦" 按钮
- 四个角落装饰符 ✦

**交互规则**:
- 点击按钮后触发翻书动画
- 动画结束后显示书页内容

**验收标准**:
- [ ] 封面显示古典魔法书风格
- [ ] 金色边框和烫金效果
- [ ] 按钮可点击且有悬停效果

#### 2.1.2 翻页系统 (BookPages)

**功能描述**: 核心浏览界面，每页展示一个奥特曼

**页面结构**:
- 左页：图像（无时代标签）
- 右页：名称（格式："名称 · 年份 · 时期"）+ 信息Tabs + 技能按钮
- 底部：翻页按钮 + 页面指示器

**交互规则**:
- 每页固定1个奥特曼（共29页）
- 点击下一页/上一页按钮翻页
- 翻页有3D动画效果（580ms）
- 翻页时重置Tab和形态选择
- 翻页时自动播放当前页名称语音（soundOn=true时）

**验收标准**:
- [x] 翻页动画流畅
- [x] 页面指示器正确显示"当前页 / 总页数"
- [x] 在首页时"上一页"按钮禁用
- [x] 在末页时"下一页"按钮禁用
- [x] 按钮热区 ≥ 44×44px
- [x] 按钮距屏幕边缘 ≥ 16px
- [x] 支持左滑/右滑手势翻页

#### 2.1.3 信息展示 (InfoTabs)

**功能描述**: 右侧页的信息切换展示

**Tab分类**:
| Tab | 内容 |
|-----|-------|
| 简介 | 剧情简介文本 |
| 形态 | 形态列表（如有）/ "无多种形态" |
| 技能 | 技能列表（逗号分隔）/ "无技能数据" |
| 人间体 | 人间体名称 / "待补充" |
| 台词 | 经典台词（斜体显示）|

**交互规则**:
- 点击Tab切换显示内容
- 翻页后自动重置到"简介"Tab

**验收标准**:
- [ ] 5个Tab正确显示
- [ ] 当前激活Tab有高亮样式
- [ ] 空数据显示占位符

#### 2.1.4 形态切换 (Forms)

**功能描述**: 有多种形态的奥特曼可切换查看

**数据示例**:
```
赛文: ["普通形态", "闪耀版"]
迪迦: ["复合型", "空中型", "强力型", "闪耀型"]
泰罗: ["普通形态", "超级形态", "少年形态"]
```

**交互规则**:
- 只有 forms.length > 0 时才显示形态按钮
- 点击形态按钮切换激活状态
- 翻页后重置到第一个形态

**验收标准**:
- [ ] 无形态显示"无多种形态"
- [ ] 有形态显示所有形态按钮
- [ ] 当前激活形态有高亮样式

#### 2.1.5 技能展示 (Skills)

**功能描述**: 显示并触发技能

**数据示例**:
```
初代: ["斯派修姆光线", "奥特屏障", "奥特水流"]
迪迦: ["哉佩利敖光线", "迪迦拉休尔光流", "兰帕尔特光弹", "迪迦计时器闪光"]
```

**交互规则**:
- 点击技能按钮触发 audio.play()
- 空技能显示"暂无技能"

**验收标准**:
- [ ] 技能按钮显示第一个技能名
- [ ] soundOn=true 时触发音频
- [ ] soundOn=false 时不触发

#### 2.1.6 音效开关 (Sound)

**功能描述**: 全局音效/语音开关，同时控制技能音效和语音朗读

**状态**:
- 🔊 开启
- 🔇 关闭

**交互规则**:
- 点击切换状态
- 影响技能音效播放和语音朗读

**验收标准**:
- [x] 点击按钮切换图标
- [x] 状态翻页后保持

#### 2.1.7 语音朗读 (Voice)

**功能描述**: 语音朗读增强儿童交互体验

**触发场景**:
| 触发条件 | 朗读内容 | 音频来源 |
|---------|---------|---------|
| 翻页进入 | 奥特曼名称 | name/{id}.mp3 |
| 点击Tab[简介] | 简介文字 | desc/{id}.mp3 |
| 点击Tab[形态] | 形态列表/"无多种形态" | forms/{id}.mp3 |
| 点击Tab[技能] | 技能列表 | skills/{id}.mp3 |
| 点击Tab[人间体] | 人间体信息 | human/{id}.mp3 |
| 点击Tab[台词] | 经典台词 | catchphrase/{id}.mp3 |

**技术方案**:
- 音频生成工具: edge-tts (免费CLI)
- 语音库: zh-CN-XiaoxiaoNeural
- 存储位置: public/audio/

**交互规则**:
- 声音默认开启 (soundOn = true)
- 翻页时自动播放当前页名称音频
- 点击Tab时播放对应内容音频
- 快速连续操作时取消前一个音频

**验收标准**:
- [x] soundOn=true 时翻页自动播放名称
- [x] soundOn=true 时Tab点击播放内容
- [x] soundOn=false 时不播放
- [x] 186个音频文件完整生成
