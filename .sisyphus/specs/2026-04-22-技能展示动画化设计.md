# 技能展示动画化设计

**项目**: Ultraman Magic Book
**日期**: 2026-04-22
**状态**: 已审批

---

## 1. 需求概述

点击技能按钮时，在左侧图片区域通过动画方式展示技能释放画面，技能动画结束后恢复原图片显示。

---

## 2. 图片命名规范

技能图片存放路径：`public/images/skills/`

命名格式：`{奥特曼名}_{技能名}.jpg`

示例：
- `迪迦_哉佩利敖光线.jpg`
- `迪迦_迪迦拉休尔光流.jpg`
- `迪迦_兰帕尔特光弹.jpg`
- `迪迦_迪迦计时器闪光.jpg`

---

## 3. 技术实现

### 3.1 图片自动匹配

```javascript
// 在 useMagicBook.js 中
const getSkillImage = (ultramanName, skillName) => {
  const sanitizedName = ultramanName.replace(/[^a-zA-Z0-9\u4e00-\u9fff]/g, '_')
  const sanitizedSkill = skillName.replace(/[^a-zA-Z0-9\u4e00-\u9fff]/g, '_')
  return `/images/skills/${sanitizedName}_${sanitizedSkill}.jpg`
}
```

### 3.2 技能动画状态

```javascript
const [activeSkill, setActiveSkill] = useState(null)      // 当前激活的技能
const [isAnimating, setIsAnimating] = useState(false)    // 动画进行中
```

### 3.3 动画逻辑

1. 用户点击技能按钮
2. 调用 `playSkill(idx)` 播放声音
3. 同时：
   - 记录当前技能名到 `activeSkill`
   - 设置 `isAnimating = true`
4. 显示技能图片（淡入淡出，300ms）
5. 技能动画持续时间后（预设3秒），恢复原图

### 3.4 技能持续时间预设

| 技能类型 | 持续时间 |
|---------|---------|
| 光线技 | 3000ms |
| 格斗技 | 2000ms |
| 特殊技 | 2500ms |

- 条件渲染：

  - 否则显示原图
