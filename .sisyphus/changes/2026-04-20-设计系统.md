### 3.2 DESIGN.md 内容大纲

```markdown
# Ultraman Magic Book Design System

## 1. Visual Theme & Atmosphere
- 古典魔法书风格
- 皮革纹理 + 金色烫金边框
- 羊皮纸书页质感
- 儿童友好的温暖色调

## 2. Color Palette & Roles
| Name | Hex | Role |
|------|-----|------|
| Magic Black | #1a0f0a | 主背景色 |
| Ancient Gold | #d4a84b | 金色边框，标题 |
| Leather Brown | #5c3d2e | 封面，标题背景 |
| Parchment | #f4e4c1 | 书页背景，卡片 |
| Warm White | #fffef5 | 文字背景 |
| Ink Black | #2c1810 | 主要文字 |
| Crimson | #8b2500 | 强调色，特效 |
| Electric Blue | #00d4ff | 发光效果 |
| Flame Orange | #ff6b00 | 技能特效 |

## 3. Typography Rules
| Element | Font | Size | Weight |
|---------|------|------|--------|
| 主标题 | Cinzel | 48px | 700 |
| 章节标题 | Cinzel | 32px | 600 |
| 卡片标题 | Noto Sans SC | 18px | 600 |
| 正文 | Noto Sans SC | 16px | 400 |
| 说明文字 | Noto Sans SC | 14px | 400 |

## 4. Component Stylings
- BookCover 组件样式
- BookPage 组件样式
- UltramanCard 组件样式
- SkillButton 组件样式
- Navigation 组件样式

## 5. Layout Principles
- 基础网格 8px
- 响应式断点 (768px, 1024px)
- 翻页魔法书布局

## 6. Depth & Elevation
- 书脊阴影
- 卡片悬停光晕
- 技能发光效果

## 7. Do's and Don'ts
- DO: 使用指定颜色
- DON'T: 添加未经批准的颜色
- DO: 遵循 3D 翻页动画
- DON'T: 使用纯黑背景 (#000000)

## 8. Responsive Behavior
- Mobile: < 768px
- Tablet: 768px - 1024px
- Desktop: > 1024px
```

### 3.3 设计准则

| 规则 | 说明 |
|------|------|
| 魔法感 | 使用金色边框 + 发光效果 |
| 复古感 | 使用 Cinzel 衬线字体 |
| 儿童友好 | 避免纯黑深色，使用暖色调 |
| 一致性 | 所有颜色通过 CSS 变量管理 |
