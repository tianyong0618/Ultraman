### 1.1 变更背景 (必需)

当前系统支持查看有多种形态的奥特曼（如赛文有普通形态和闪耀版），但形态切换只显示文字按钮，图片不会随形态切换而变化。用户希望点击不同形态时，图片也能切换到对应形态。

### 1.2 变更目的 (必需)

- 形态切换时，左页图片自动切换到对应形态的图片
- 每个形态可以包含特有的技能（如赛文闪耀版有专属技能）
- 为所有有多种形态的奥特曼获取并下载对应形态图片

### 1.3 影响范围 (必需)

- `src/data/ultraman.js` - 扩展forms数据结构
- `src/components/PageLeft.jsx` - 支持形态图片切换
- `src/components/UltramanInfo.jsx` - 形态按钮绑定事件
- `src/hooks/useMagicBook.js` - 管理activeForm对图片的影响

## 3. 技术方案设计 (建议)

### 3.1 实现思路

1. **数据结构扩展**：将forms从字符串数组改为对象数组：
```js
// 修改前
forms: ['普通形态', '闪耀版']

// 修改后
forms: [
  { name: '普通形态', image: '/images/ultraman/03_赛文.jpg', skills: ['集束射线', '艾梅利射线'] },
  { name: '闪耀版', image: '/images/ultraman/03_赛文_闪耀版.jpg', skills: ['集束射线', '闪耀光束'] }
]
```

2. **图片获取**：使用搜索引擎批量搜索下载：
   - 搜索 "[奥特曼名] [形态名] Ultraman"
   - 下载到 `public/images/ultraman/` 目录
   - 文件命名: `{id}_{形态名}.jpg`

3. **组件修改**：
   - `PageLeft`: 根据activeForm显示对应形态的image
   - `UltramanInfo`: 形态按钮绑定onClick，切换activeForm
   - `useMagicBook`: 管理activeForm状态

### 3.2 关键修改点

- `PageLeft` 需要接收 `activeForm` 或 `currentFormImage`
- 技能展示需要优先显示形态特有技能，无则显示父级技能

### 3.3 风险与应对

- 图片搜索不到：使用备用搜索词或使用默认图片
- 形态数据多：分批处理，先处理有形态的奥特曼
