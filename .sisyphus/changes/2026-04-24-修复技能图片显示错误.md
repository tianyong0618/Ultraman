## 4. 技术方案设计

### 4.1 根本原因

`playSkill` 函数接收 `skillIndex`（技能在 displaySkills 中的索引），但内部使用 `current.skills[skillIndex]` 获取技能名。

- `displaySkills` 是当前形态的技能列表
- `current.skills` 是该奥特曼所有技能的列表

两个数组顺序不同，导致索引错位。例如梦比优斯凤凰形态：
- `displaySkills = ['梦比优斯爆裂', '扎古光线']`
- `current.skills = ['梦比优斯光线', '梦比优斯爆裂', '扎古光线']`

点击索引 1（扎古光线）时，`current.skills[1]` = '梦比优斯爆裂' ❌

### 4.2 修复方案

改为传递技能名而非索引，消除数组依赖：

```javascript
// Before: playSkill(skillIndex) → current.skills[skillIndex] ❌
// After:  playSkill(skillName) → 直接使用 skillName ✓
```
