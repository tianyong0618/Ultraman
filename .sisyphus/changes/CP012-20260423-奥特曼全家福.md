## 1. 变更概述

| 项目 | 内容 |
|------|------|
| 变更编号 | CP-012 |
| 变更日期 | 2026-04-23 |
| 申请人 | 田勇 |
| 优先级 | P1 |
| 影响范围 | 全家福页面、书页Tab、关系筛选 |

### 1.1 变更背景

用户希望增加一个展示所有奥特曼关系的全家福页面，同时在书页中通过"关系"Tab查看当前奥特曼与其他奥特曼的关系。

### 1.2 变更目的

- 提供全屏星空背景展示全部29个奥特曼头像
- 通过光束连线展示奥特曼之间的关系
- 点击头像快速跳转到对应书页
- 书页新增"关系"Tab，显示关系列表并支持筛选查看

### 1.3 影响范围

| 文件 | 操作 |
|------|------|
| `src/components/FamilyPortrait.jsx` | 新增 |
| `src/components/UltramanInfo.jsx` | 修改 |

| `src/App.jsx` | 修改 |
| `src/data/ultraman.js` | 修改 |
| `src/index.css` | 修改 |

## 4. 技术方案设计

### 4.1 实现思路

- 新增 `FamilyPortrait` 组件处理全家福页面渲染
- 使用 SVG 绘制关系连线
- 使用 CSS 动画实现星空背景
- 关系数据存储在 `ultraman.js` 中

### 4.2 关键修改点

- `ultraman.js`: 添加 `ultramanRelations` 数据，修改 `infoLabels`
- `App.jsx`: 添加全家福相关状态管理
- `UltramanInfo.jsx`: 处理"关系"Tab点击事件

### 4.3 风险与应对

- 头像位置随机算法可能产生重叠 → 使用间距检查算法确保最小距离
