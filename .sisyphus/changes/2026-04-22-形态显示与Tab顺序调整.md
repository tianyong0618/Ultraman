# 形态显示与Tab顺序调整

**变更编号**: CP-022
**变更日期**: 2026-04-22
**申请人**: 用户
**优先级**: P1
**影响范围**: UltramanInfo.jsx, ultraman.js

---

## 1. 变更概述

修改形态的显示逻辑和Tab标签顺序：
- 无形态时显示"普通形态"而非"无多种形态"
- 调整Tab标签顺序：形态 → 简介 → 人间体 → 台词

---

## 2. 详细需求与验收标准

### REQ-001: 无形态显示普通形态
- **需求**: 当奥特曼数据中 `forms` 数组为空时，形态Tab显示"普通形态"
- **验收**: 初代奥特曼、杰克、艾斯等无形态的奥特曼显示"普通形态"按钮

### REQ-002: Tab顺序调整
- **需求**: Tab标签顺序变为 `['形态', '简介', '人间体', '台词']`
- **验收**:
  - 默认激活形态Tab（index 0）
  - 切换后正确显示对应内容

---

## 3. 变更内容

### 3.1 UltramanInfo.jsx

1. TabContent中 `activeTab === 3` 的判断改为对应新顺序:
   - index 0: 形态（原index 3）
   - index 1: 简介（原index 0）
   - index 2: 人间体（原index 1）
   - index 3: 台词（原index 2）

2. 无形态时显示"普通形态":
   ```javascript
   current.forms.length === 0 ? (
     <button className="form-button active">普通形态</button>
   ) : (...)
   ```

### 3.2 ultraman.js

```javascript
export const infoLabels = ['形态', '简介', '人间体', '台词']
```

---

## 4. 验收标准

- [ ] 初代奥特曼显示"普通形态"按钮
- [ ] Tab默认停留在形态
- [ ] 形态 → 简介 → 人间体 → 台词 顺序正确
- [ ] 各Tab点击后显示正确内容
