| 影响范围 | useMagicBook.js, PageLeft.jsx, App.jsx, index.css |

### 1.1 变更背景 (必需)

当前系统点击技能按钮时只播放声音，没有视觉反馈。用户希望点击技能时在图片区域展示技能释放的动画效果。

### 1.2 变更目的 (必需)

- 点击技能按钮时显示技能图片（动画效果）
- 技能持续3秒后自动恢复原图
- 技能图片使用自动匹配方式（{奥特曼名}_{技能名}.jpg）

### 1.3 影响范围 (必需)

- `src/hooks/useMagicBook.js` - 添加技能动画状态
- `src/components/PageLeft.jsx` - 技能图片渲染
- `src/App.jsx` - 传递 props
- `src/index.css` - 动画样式
- `public/images/skills/` - 技能图片目录

## 2. 详细需求与验收标准 (必需)

### 2.1 功能需求

## 3. 实施方案

### 3.1 技术方案

使用方案C（自动匹配）：
- 技能图片路径：`/images/skills/{奥特曼全名}_{技能名}.jpg`
- 例如：`/images/skills/迪迦奥特曼_哉佩利敖光线.jpg`

### 3.2 状态管理

```javascript
const [activeSkill, setActiveSkill] = useState(null)
const [isSkillAnimating, setIsSkillAnimating] = useState(false)
```

### 3.3 动画效果

- 淡入：opacity 0 → 1, scale 0.95 → 1
- 金色光晕：box-shadow glow 效果
