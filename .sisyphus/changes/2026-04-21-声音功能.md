## 1. 需求背景

### 1.1 问题陈述

当前奥特曼魔法书应用仅有视觉展示功能，缺乏语音交互能力。用户 希望新增声音功能，增强4岁儿童的交互体验。

### 1.2 用户需求

| 需求编号 | 需求描述 | 优先级 |
|---------|---------|--------|
| VOICE-001 | 声音功能默认开启 | P0 |
| VOICE-002 | 每打开一页，朗读该页奥特曼的名字 | P0 |
| VOICE-003 | 点击「简介」按钮后，朗读简介内容 | P0 |
| VOICE-004 | 点击「形态」按钮后，朗读形态信息（无形态时朗读"无多种形态"） | P0 |
| VOICE-005 | 点击「技能」按钮后，朗读技能列表 | P1 |
| VOICE-006 | 点击「人间体」按钮后，朗读人间体信息 | P1 |
| VOICE-007 | 点击「台词」按钮后，朗读经典台词 | P1 |
| VOICE-008 | 可手动关闭/开启声音 | P0 |
| VOICE-009 | 无额外费用产生 | P0 |

### 1.3 成功标准

- [ ] VOICE-001: 声音功能默认开启，应用启动时 soundOn = true
- [ ] VOICE-002: 翻页时自动播放当前页奥特曼名称音频
- [ ] VOICE-003: 点击「简介」Tab时播放 `desc/{id}.mp3`
- [ ] VOICE-004: 点击「形态」Tab时播放 `forms/{id}.mp3`（无形态时播放"无多种形态"）
- [ ] VOICE-005: 点击「技能」Tab时播放 `skills/{id}.mp3`
- [ ] VOICE-006: 点击「人间体」Tab时播放 `human/{id}.mp3`
- [ ] VOICE-007: 点击「台词」Tab时播放 `catchphrase/{id}.mp3`
- [ ] VOICE-008: 点击🔊/🔇按钮切换声音状态
- [ ] VOICE-009: 使用edge-tts免费工具生成音频，无API费用

## 3. 用户界面变更

### 3.1 现有界面（保持不变）

| 区域 | 内容 |
|------|------|
| 左页 | 奥特曼图片 |
| 右页 | 信息展示（5个Tab：简介/形态/技能/人间体/台词） |
| 底部 | 翻页导航（prev/next按钮） |
| 右上角 | 声音开关按钮（🔊/🔇） |

### 3.2 新增交互

| 交互 | 触发条件 | 响应动作 |
|------|---------|---------|
| 翻页播放 | 用户点击prev/next或手势滑页 | 播放 `name/{currentId}.mp3` |
| Tab点击播放 | 用户点击任一Tab按钮 | 播放对应类型音频 `{tabType}/{currentId}.mp3` |
| 声音切换 | 点击🔊/🔇按钮 | 切换 `soundOn` 状态 |

### 3.3 数据流

```
用户翻页
  │
  ├── setCurrentPage(pageId)
  │
  └── playNameAudio(pageId)
      │
      └── new Audio(`/audio/name/${pageId}.mp3`).play()

用户点击Tab
  │
  ├── setActiveTab(tabIndex)
  │
  └── playTabAudio(tabIndex)
      │
      └── tabs = ['desc', 'forms', 'skills', 'human', 'catchphrase']
      │
      └── new Audio(`/audio/${tabs[tabIndex]}/${pageId}.mp3`).play()
```

### 3.4 组件变更

| 文件 | 变更内容 |
|------|---------|
| `src/hooks/useMagicBook.js` | 添加 `playAudio(type)` 和 `playTabAudio(tabIndex)` 函数 |
| `src/components/UltramanInfo.jsx` | 修改Tab点击回调，同时触发音频播放 |
| `src/components/Navigation.jsx` | 修改翻页回调，同时触发名称音频播放 |
