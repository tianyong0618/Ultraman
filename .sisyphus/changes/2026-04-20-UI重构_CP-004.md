# UI 重构 - 变更提案

## 1. 变更概述

| 项目 | 内容 |
|------|------|
| 变更编号 | CP-004 |
| 变更日期 | 2026-04-20 |
| 申请人 | - |
| 优先级 | P1 |
| 影响范围 | UI 样式层重构，不影响业务逻辑 |

### 1.1 变更背景

当前 Ultraman Magic Book 系统的 UI 样式 (`src/index.css` 和各组件) 存在以下问题：
1. **CSS 变量不完整** - 缺少间距、阴影、圆角等设计 tokens
2. **动画定义重复** - `starGlow` 动画在 `index.css` 中定义两次
3. **组件逻辑错误** - `UltramanInfo.jsx` 中 FormButton 激活状态判断使用 `activeTab === idx`，应该是 `activeForm`
4. **响应式断点不完整** - 缺少 Tablet (768-1024px) 断点
5. **可访问性缺失** - 缺少 ARIA 属性

### 1.2 变更目的

严格遵循项目根目录 `DESIGN.md` 设计规范，统一 UI 样式系统，提升代码质量和可维护性。

### 1.3 影响范围

| 文件 | 变更类型 | 影响 |
|------|----------|------|
| `src/index.css` | 重构 | CSS 变量系统增强 |
| `src/components/UltramanInfo.jsx` | 修复 | 激活状态逻辑修复 |
| `src/components/BookCover.jsx` | 保持 | 无需修改 |
| `src/components/PageLeft.jsx` | 增强 | 可选 ARIA |
| `src/components/Navigation.jsx` | 增强 | 可选 ARIA |
