# 翻页方式优化 - 变更提案

## 1. 变更概述

| 项目 | 内容 |
|------|------|
| 变更编号 | CP-005 |
| 变更日期 | 2026-04-20 |
| 申请人 | Sisyphus |
| 优先级 | P1 |
| 影响范围 | Navigation.jsx、index.css、usePageFlip.js（需新增） |

### 1.1 变更背景

当前翻页按钮存在以下问题：
1. **按钮可点击区域过小** - 字符 `›` 和 `‹` 的视觉尺寸与实际点击热区不匹配，用户难以准确点击
2. **距离屏幕边缘过近** - 当前按钮距离屏幕边缘仅 8px（`var(--space-sm)`），在移动设备上容易误触系统返回/手势区域，导致应用意外退出
3. **缺乏手势交互** - 仅支持按钮点击，不支持直观的滑动翻页体验

### 1.2 变更目的

| 目标 | 描述 |
|------|------|
| T1 | 增大翻页按钮的可点击热区，至少达到 44×44px（iOS HIG 推荐的最小点击尺寸） |
| T2 | 增加按钮与屏幕边缘的安全间距，至少 16px，避免误触 |
| T3 | **新增** 支持手指/鼠标滑动翻页，呈现翻书效果 |

### 1.3 影响范围

- **受影响组件**：`src/components/Navigation.jsx`
- **受影响样式**：`src/index.css`（第 501-543 行）
- **新增文件**：`src/hooks/usePageFlip.js`

## 3. 技术方案设计

### 3.1 实现思路

**推荐方案：渐进增强方案**

保持按钮点击 + 新增滑动翻页，两种方式共存。

理由：
1. 保留原有交互习惯，现有用户无需重新学习
2. 滑动翻页为新增能力，对用户无学习成本
3. 按钮对无障碍访问（键盘）友好

#### 3.1.1 按钮样式优化

| 属性 | 当前值 | 目标值 | 说明 |
|------|--------|--------|------|
| 最小高度 | 48px（字体） | 48px | 视觉高度 |
| 最小宽度 | 32px（字体） | 64px | 扩大热区 |
| padding | 无 | 16px 20px | 扩展热区 |
| margin-inline-start | var(--space-sm)（8px） | 16px | 边缘安全距离 |
| margin-inline-end | var(--space-sm)（8px） | 16px | 边缘安全距离 |

**触摸热区优化技巧**：
```css
/* 使用伪元素扩展不可见热区 */
.nav-button::before {
  content: '');
  position: absolute;
  inset: -8px;  /* 扩展 8px 不可见热区 */
}
```

#### 3.1.2 滑动翻页实现

**推荐：自实现 Pointer Events 处理器**（不引入额外依赖）

```javascript
// 手势识别参数
const SWIPE_THRESHOLD = 50;        // 最小滑动距离 (px)
const SWIPE_VELOCITY = 0.3;       // 最小滑动速度 (px/ms)
const FLIP_DURATION = 400;        // 翻页动画时长 (ms)
```

**手势流程**：
```
start → move → [distance > threshold] → determine direction → trigger flip → end
           ↓
        [distance < threshold] → reset position → end
```

#### 3.1.3 翻书动画效果

**左滑（下一页）**：
- 当前页绕左侧轴顺时针旋转 180° 消失
- 新页从右侧逆时针旋转 180° 进入

**右滑（上一页）**：
- 当前页绕右侧轴逆时针旋转 180° 消失
- 新页从左侧顺时针旋转 180° 进入

**CSS 动画**：复用现有 `flipLeftPage` / `flipRightPage` 动画（index.css 第 641-661 行），或新增基于 `translateX` 的滑动动画。

### 3.2 关键修改点

| 文件 | 修改内容 |
|------|---------|
| `src/components/Navigation.jsx` | 增加手势处理 props（onSwipeLeft、onSwipeRight） |

### 3.3 风险与应对

| 风险 | 应对措施 |
|------|---------|
| 手势与页面内滚动冲突 | 添加滚动区域检测，仅在非滚动区域响应手势 |
| 动画卡顿 | 使用 `transform` + `will-change` 优化 |
| 边缘误触（移动端） | 添加 16px 边缘检测区 |
