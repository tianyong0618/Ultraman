# 信息项展示优化 - 变更提案

## 1. 变更概述

| 项目 | 内容 |
|------|------|
| 变更编号 | CP-006 |
| 变更日期 | 2026-04-21 |
| 申请人 | Sisyphus |
| 优先级 | P2 |
| 影响范围 | UltramanInfo.jsx、PageLeft.jsx、index.css |

### 1.1 变更背景

当前页面信息展示存在以下问题：
1. **右侧名称行信息分散** - 名称、年份、系列分两行显示，不够紧凑
2. **年代信息重复** - 左侧照片下方显示年代，右侧也显示年份和系列，年代信息出现多次
3. **移动端翻页按钮点击区域问题** - 按钮热区可能与页面内容重叠，用户容易点错

### 1.2 变更目的

| 目标 | 描述 |
|------|------|
| T1 | 统一右侧名称展示格式为 "名称 · 年份 · 年代"，居中显示 |
| T2 | 删除右侧多余的年份系列显示行，避免信息重复 |
| T3 | 删除左侧照片下的年代显示，避免与右侧重复 |
| T4 | 优化移动端翻页按钮点击区域，减少与页面内容重叠 |

### 1.3 影响范围

- **受影响组件**：`src/components/UltramanInfo.jsx`、`src/components/PageLeft.jsx`
- **受影响样式**：`src/index.css`

## 3. 技术方案设计

### 3.1 实现思路

1. **REQ-001, REQ-002**: 修改 `UltramanInfo.jsx` 中的 JSX，将 `<h2 className="ultraman-name">` 和 `<p className="ultraman-year">` 合并为一个元素，格式为 `{name} · {year} · {era}`，并在 CSS 中添加 `text-align: center`

2. **REQ-003**: 删除 `<p className="ultraman-year">` 行，因为信息已合并到名称行中

3. **REQ-004**: 修改 `PageLeft.jsx`，删除 `<p className="page-left-title">` 行

4. **REQ-005**: 修改 `index.css` 中 `.nav-button` 的移动端样式，增加 margin 或调整热区

### 3.2 关键修改点

| 文件 | 修改内容 |
|------|---------|
| src/components/UltramanInfo.jsx | 合并名称显示行，删除年份系列行 |
| src/components/PageLeft.jsx | 删除 page-left-title 元素 |
| src/index.css | 添加 text-align: center，优化移动端按钮热区 |

### 3.3 风险与应对

| 风险 | 应对措施 |
|------|---------|
| 响应式布局适配 | 在不同屏幕尺寸下测试确认显示正常 |
| 数据字段缺失 | 检查 ultraman.js 中 era 字段是否所有记录都有值 |
